# Code of Conduct

This project is committed to providing a welcoming and inclusive environment for all contributors and users.

## Our Standards

We expect all community members to:

- **Be respectful** — Treat others with kindness and professionalism
- **Be constructive** — Provide helpful feedback and criticism
- **Be collaborative** — Work together toward the project's goals
- **Be inclusive** — Welcome contributors from all backgrounds and experience levels
- **Be honest** — Acknowledge limitations, ask for help, and don't misrepresent work

## Unacceptable Behavior

The following behaviors are unacceptable and may result in removal:

- Harassment, discrimination, or hate speech based on any protected characteristic
- Trolling, deliberate misinformation, or bad-faith arguments
- Spam or off-topic content
- Aggressive or threatening language

## Reporting

If you experience or witness a violation, please report it to the maintainers privately. We will handle all reports confidentially and investigate thoroughly.

---

**Participation in this project implies acceptance of this Code of Conduct.**
